===== LUM-1485 terminal title (OSC 0) through the real bridge. Nothing here is visible in the frames on purpose: a window/tab title is terminal state, not cell content, so pages 1-4 are checked by `raw_expect`/`raw_reject` against the byte trace each panel produced. Panel 1 is the automatic title `pi - <cwd>`; panel 2 is `/name demo`, which recomposes it to `pi - demo - <cwd>`; panel 3 is an extension calling `ctx.ui.setTitle` from a slash command (the footer row `handler ran` proves the handler executed); panel 4 is the same call with BEL+ESC inside the title, which must reach the terminal fully neutralised. Commands are sent as two steps — text, a 0.4s pause, then Enter — because a single instantaneous write is classified as a paste burst (LUM-1461) and an Enter inside the burst window is inserted as the paste's trailing newline instead of submitting.
